# Amazon Clone Website

## Description

This project is a clone of the Amazon website. It is built using HTML, CSS, and Vanilla JavaScript. The project is 
complete.

## Features

### Basics

- Home page
- Checkout page
- Orders page
- Tracking page

### Functions

- Add to cart
- Remove from cart
- Update quantity
- Delete product from checkout
- Update delivery option
- Place order
- Search for products
- Buy again to create new order
- Track package

It uses backend to create orderId and orderTime for each order. Thanks to @supersimpledev for providing the base 
code and support for backend for this project as well as learning JS from him. Please support his channel here: 
[SuperSimpleDev](https://www.youtube.com/@SuperSimpleDev/)
